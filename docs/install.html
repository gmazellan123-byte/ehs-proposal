안전제안 앱 설치

안전 개선제안 · 아차사고 신고

Chrome에서 설치하면 앱 서랍과 홈 화면에 안전제안 아이콘이 생기고, 주소창 없이 앱처럼 전체화면으로 실행됩니다. 별도 설치 파일이나 보안 설정 변경이 필요 없습니다.

Chrome에서 열어 설치하기
  1. 위 버튼을 누르면 Chrome에서 안전제안 화면이 열립니다.
  2. 로그인 화면 아래 앱으로 설치하기의 [설치]를 누릅니다.
    (버튼이 없으면 Chrome 오른쪽 위 ⋮ → 앱 설치)
  3. 설치 창에서 설치를 누릅니다.
  4. 앱 서랍·홈 화면의 안전제안 아이콘으로 실행해 사번과 비밀번호로 로그인합니다.
예전에 받은 설치 파일(APK)로 깐 안전제안 앱이 있으면 삭제한 뒤 위 방법으로 다시 설치해 주세요.
설치 없이 웹으로 바로 사용하기
아이폰은 Safari에서만 홈 화면에 추가할 수 있습니다. 아래 주소를 복사해 Safari에서 열어 주세요.

아이폰은 설치 파일 없이 홈 화면에 추가하면 앱처럼 전체화면으로 실행됩니다.

안전제안 열기
  1. 위 버튼으로 안전제안 화면을 Safari에서 엽니다.
  2. 화면 아래의 공유 버튼(네모에 위쪽 화살표)을 누릅니다.
  3. 메뉴를 아래로 내려 홈 화면에 추가를 누르고, 오른쪽 위 추가를 누릅니다.
  4. 홈 화면에 생긴 안전제안 아이콘으로 실행합니다. 주소창 없이 열립니다.

로그인은 사번과 본인이 정한 비밀번호로 합니다.
처음이면 화면의 [최초 등록]에서 비밀번호를 설정하세요.
