반영 규칙 RULES

  • 모든 조직 구분은 사번 기준입니다. 근로자 화면에는 소속이 표시되지 않고, 제출건은 사번의 소속으로 자동 분류됩니다.
  • 새 사번은 등록되고, 이미 있는 근로자·관리자는 그룹·팀·파트가 갱신됩니다.
  • 권한 칸이 비어 있으면 신규는 근로자, 기존 인원은 현재 권한을 유지합니다.
  • 사업팀·본사 계정은 업로드로 바뀌지 않습니다.
  • 그룹명은 서버 조직표와 정확히 같아야 합니다 (양식의 [그룹목록] 시트 참고).
  • 성명은 브라우저에서 마스킹(예: 홍길동 → 홍*동)된 뒤 전송되며, 원래 성명은 서버 어디에도 저장되지 않습니다.
  • 업로드 파일은 서버에 저장되지 않습니다. 사번은 HTTPS로 전송되어 서버에서 암호화된 값으로만 저장됩니다.
  • 이미 가입한 직원의 소속이 바뀌어도 로그인 정보는 그대로 유지되며, 이후 제출건부터 새 소속으로 분류됩니다.
